# 具身智能算法工程师 · 系统学习论文库

> 一套按研究方向组织的中文论文学习库：11 个方向 + 2 个方法论工具 · 必读论文精读 · 技术演进脉络 · 开源资源 · 自测题。
> 目标：用 3-6 个月建立完整的具身智能知识体系，并具备动手复现与二次开发的能力。

---

## 0. 这套文档怎么用（先读这里）

**核心方法论：建图 → 主线 → 动手 → 自测 → 输出**

1. **建图（约 3 天）**：通读本页与 [01_领域全景与必读综述.md](01_领域全景与必读综述.md)，弄清每个方向解决什么问题、彼此是什么关系，亲手画一张领域脑图。
2. **主线精读（8-10 周）**：按 §3 路线推进。每篇精读论文用"四问法"：
   - 它解决什么问题？为什么之前的方法不行？
   - 核心思想用一句话是什么？
   - 方法细节：输入输出、模型结构、训练流程、关键取舍。
   - 局限是什么？给了你什么启发？
3. **动手验证（贯穿全程）**：每个核心方向至少跑通一个开源项目（见 §4 清单）。只读不练 = 白学。
4. **自测闭环**：各方向文档 §6 有自测题，答不出来就回去重读对应部分；方法论文档可直接用于每周复盘。
5. **输出倒逼输入**：每篇精读写 300 字笔记；阶段成果整理成博客/开源仓库——这就是你的面试作品集。

**节奏建议**：每周 2-3 篇精读 + 1-2 次动手实验。宁可慢，不可浅。

## 3. 推荐学习路线（16 周模板，可压缩到 8 周）

### 阶段一：建图 + 环境（第 1-2 周）
- 精读 01 文档中的 3-4 篇全景综述（跳读法：摘要 → 图 → 结论 → 实验表）
- 环境搭建：安装 Isaac Lab 或 MuJoCo + Hugging Face LeRobot，各跑通一个官方示例
- ✅ 产出：自己手绘的领域地图；可运行的本地环境

### 阶段二：核心主线（第 3-8 周）
- **第 3-4 周 · 操作**：读 03；在 robomimic/LIBERO 上跑 Diffusion Policy 与 ACT 做对比
- **第 5-6 周 · VLA**：读 02；用 openpi 或 LeRobot 微调一个 VLA（小数据集即可，重点是走通全流程）
- **第 7 周 · 数据与平台**：读 08；精读 Open X-Embodiment 与 DROID，理解"数据规模化"的行业逻辑
- **第 8 周 · Sim2Real**：读 09；在 Isaac Lab 里完整跑一次带 domain randomization 的训练
- ✅ 产出：1 个可演示的复现项目 + 精读笔记

### 阶段三：广度扩展（第 9-12 周）
按意向从 P1/P2 中选 3 个方向：
- 想做**机器人大脑**：11 → 07
- 想做**运动控制/人形**：05 → 06
- 想做**导航与空间**：04 → 10
- ✅ 产出：每个方向 1 份"技术脉络 + 关键论文"笔记（可直接以本库文档为骨架补充）

### 阶段四：前沿追踪 + 作品集（第 13-16 周）
- 选一个细分点（如 VLA 高效微调、灵巧手 RL、世界模型策略学习）深挖最新 3-5 篇工作
- 完成一个作品集项目（改结构/换数据/加功能，而不是纯复现），写成博客开源出去
- ✅ 产出：GitHub 项目 + 技术博客——这就是你的敲门砖

## 6. 给转型工程师的 5 条心法

1. **数据 > 模型**：具身智能当前最大的瓶颈是数据规模化。读任何论文都问一句："训练数据从哪来、能怎么扩？"
2. **先仿真后实物**：现代机器人学习几乎都是"仿真中先赢、真机上验证"，掌握仿真栈就是掌握入场券。
3. **演进逻辑 > 单点模型**：RT-1 → RT-2 → π0/OpenVLA 的问题链比任何单个模型都更值钱，面试考的往往是这条线。
4. **自测题 ≈ 面试题库**：各文档 §6 的问题覆盖高频面试考点（VLA 动作生成三大流派、sim2real 手段、ACT 为什么有效……）。
5. **以输出倒逼输入**：写笔记、写博客、开源复现，比把论文重读三遍更有效。

## 9. 从论文到岗位的表达顺序

面试和作品集都建议按以下顺序组织：

1. **问题**：真实约束是什么，为什么现有方法不够；
2. **地图**：所属方向、代表工作和演进关系；
3. **选择**：为什么选这条技术路线，放弃了什么；
4. **证据**：数据、指标、消融和失败案例；
5. **工程**：延迟、安全、标定、日志和复现；
6. **下一步**：当前局限和最有价值的后续实验。

不要按论文章节顺序背诵，按“我如何做判断”的顺序表达。
